# Ziggy & Gretel's Hebrew Adventure

Hebrew learning games for Noa, played at **https://heller23-wq.github.io/noa-hebrew/**

- `index.html` – the app (games, 3D island, star shop)
- `voice/` – recorded voices (Microsoft Azure neural voices: Ollie and Ada in English, Avri and Hila in Hebrew), packed into one file per language with `index.json` pointing at each clip
- `three.min.js` – the three.js 3D library (r128)

On an iPad: open the address in Safari, then Share → Add to Home Screen.
